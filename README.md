# 🧮 SmartCalc Pro

A modern and responsive calculator built using HTML, CSS, JavaScript, and Bootstrap. This project was created to practice JavaScript fundamentals while using a professional dashboard template.

## ✨ Features

- Basic arithmetic operations (+, −, ×, ÷)
- Responsive design
- Clean Bootstrap UI
- Calculator display
- History panel
- AC and DEL buttons
- Decimal support
- Percentage calculations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 4
- SB Admin 2 Template

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/smartcalc-pro.git
```

2. Open the project folder.

3. Open `index.html` in your browser or run it with Live Server.
